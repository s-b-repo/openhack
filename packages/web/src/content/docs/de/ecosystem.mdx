Eine Sammlung von Community-Projekten, die auf OpenHack basieren.

:::note
Möchten Sie Ihr OpenHack-bezogenes Projekt zu dieser Liste hinzufügen? Senden Sie einen PR.
:::

Sie können sich auch [awesome-openhack](https://github.com/awesome-openhack/awesome-openhack) und [openhack.cafe](https://openhack.cafe) ansehen, eine Community, die das Ökosystem und die Community zusammenfasst.
