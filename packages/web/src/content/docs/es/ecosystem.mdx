Una colección de proyectos comunitarios construidos en OpenHack.

:::note
¿Quieres agregar tu proyecto relacionado con OpenHack a esta lista? Envíe un PR.
:::

También puedes consultar [awesome-openhack](https://github.com/awesome-openhack/awesome-openhack) y [openhack.cafe](https://openhack.cafe), una comunidad que agrega el ecosistema y la comunidad.
