---
description: Toggle the Command Advisor or get advice on a command
---
Manage the Command Advisor for $ARGUMENTS.
If no args: toggle advisor ON/OFF.
If "test <command>": analyze a command and show tips, warnings, and alternatives.
If "level <1-3>": set advisor verbosity (1=errors only, 2=+tips, 3=+alternatives).
The advisor has knowledge of 26+ tools (nmap, sqlmap, hydra, hashcat, ffuf, masscan, etc.) plus MCP-specific advice for all 5 MCP servers.
